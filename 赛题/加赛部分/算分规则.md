# 算分规则

## 一、总分构成
预赛积分榜前50名无需参加

本次比赛计分总分为 **700 分**，由原有赛题的 **620 分**与加赛的两项排名分组成。

| 计分部分 | 满分 | 计算方式 |
| --- | ---: | --- |
| 原有赛题 | 620 分 | 按各赛题原有规则汇总实际得分 |
| 加赛性能排名 | 40 分 | 独立排名，第一名 40 分，每下降一名减 0.5 分，最低 0 分 |
| 加赛 Agent prompt 评价排名 | 40 分 | 独立排名，第一名 40 分，每下降一名减 0.5 分，最低 0 分 |
| **合计** | **700 分** |  |


**最终总分 = 原有赛题实际得分 + 加赛性能排名分 + 加赛 Agent prompt 排名分。**

620 分是原有赛题的满分，不是每位选手直接获得的基础分。原有赛题计分规则不变；后两项分别按各自榜单排名换算，不直接使用性能指标或 Agent 原始评价分作为比赛得分。

## 二、加赛计分前提
加赛的全部正式 MySQL case 必须通过，才有资格获得后两项排名分。MySQL case 不单独计分。

+ 未参加加赛或没有全部通过 MySQL case 的有效版本：两项加赛得分均为 0，不占对应榜单名次。
+ MySQL case 全部通过：分别进行性能评测和 Agent prompt 评价。
+ 性能评测无效：性能分为 0，不占性能榜名次；符合要求的 Agent prompt 材料仍可参与评价排名。
+ Agent prompt 材料未提交、不可读取或无有效学习材料：该项为 0，不占评价榜名次；符合要求的性能结果仍可参与性能排名。

**加赛未通过不影响原有赛题已经取得的分数，不会将原有 620 分部分清零。** 平台故障按加赛文档的重测规则处理。

## 三、两项排名的梯度计分
### 3.1 性能排名分
根据加赛文档规定的耗时、磁盘 I/O、峰值内存及权重计算综合性能指标，由高到低排序。设性能排名为 r_perf，从 1 开始：

**性能排名分 = max(40 − 0.5 × (r_perf − 1), 0)**

### 3.2 Agent prompt 排名分
Agent 按问题理解与学习规划、Prompt 设计与迭代、验证纠错与独立判断、总结复盘与知识迁移等多个维度评审材料，形成原始评价分，并据此独立排序。原始评价分只用于排名，不直接计入比赛总分。

设 Agent prompt 排名为 r_prompt，从 1 开始：

**Agent prompt 排名分 = max(40 − 0.5 × (r_prompt − 1), 0)**

### 3.3 排名与得分对照
两项排名均使用下表，各自独立计算：

| 排名 | 该项得分 |
| ---: | ---: |
| 1 | 40 |
| 2 | 39.5 |
| 3 | 39 |
| 10 | 35.5 |
| 20 | 30.5 |
| 40 | 20.5 |
| 60 | 10.5 |
| 80 | 0.5 |
| 81 及以后 | 0 |


同一位选手在两项中的排名可以不同。例如性能排名第 2、Agent prompt 排名第 5，则加赛得分为 **39.5 + 38 = 77.5 分**。

### 3.4 并列规则
两榜均采用竞赛排名：并列选手获得相同名次和分数，后续名次跳过并列人数。例如两人并列第一，下一人为第三，三人的对应分数为 40、40、39 分。

性能指标的比较精度及 Agent 原始评价分的汇总方式，以加赛文档为准；不以提交先后打破原始指标相同的并列。

## 四、最终参评版本与成绩结算
每位选手在截止前从自己的正式提交中指定一个最终参评版本；未指定时，采用最优一次 MySQL case 全部通过的正式提交。没有通过版本时，加赛得分为 0。

性能和 Agent prompt 必须对应同一次提交锁定的源码、Dockerfile 和 prompt 文件，不得拼接不同版本的最佳结果。每位选手在每个榜单最多占一个名次。

比赛期间显示暂定排名和分数；截止并完成复核后，按所有最终参评版本分别生成两个榜单，再计算最终总分。新增有效参评结果或复核调整可能改变名次，因此不能沿用比赛过程中的历史最高排名分。

## 五、计算示例
| 情况 | 原有赛题实际得分 | 性能排名分 | Agent prompt 排名分 | 最终总分 |
| --- | ---: | ---: | ---: | ---: |
| 两项均排名第一 | 620 | 40 | 40 | **700** |
| 性能第 2，Agent prompt 第 5 | 560 | 39.5 | 38 | **637.5** |
| MySQL case 未全部通过 | 560 | 0 | 0 | **560** |
| 性能无效，Agent prompt 第 3 | 560 | 0 | 39 | **599** |
| 两项均排名第 81 | 560 | 0 | 0 | **560** |
